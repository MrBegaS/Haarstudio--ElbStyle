# Haarstudio ElbStyle

A premium, responsive landing page for a fictional hair salon in Hamburg, Germany.

## Overview
This project was created to present a modern, upscale salon brand with a luxury aesthetic, clear service structure, and strong conversion-focused UX. The website is built with pure HTML, CSS, and JavaScript and is designed to work well on desktop, tablet, and mobile devices.

## Features
- Premium salon-inspired visual identity
- Responsive layout for all screen sizes
- Service highlights and pricing information
- Gallery section with filtering interaction
- Testimonials and social proof
- Contact form and CTA sections
- Structured metadata for SEO and local business visibility
- Clean, semantic HTML structure

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Static website deployment

## Project Structure
- `index.html` – page structure and content
- `styles.css` – visual design, layout, responsiveness, and animation
- `script.js` – navigation, gallery filtering, scroll effects, and form behavior
- `robots.txt` – crawler instructions
- `sitemap.xml` – sitemap for search engines
- `README.md` – local setup and deployment notes

## Local Run
Open the project folder and run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment
