Haarstudio ElbStyle – Premium Hair Salon Landing Page

Opis projekta:
I designed and developed a premium, responsive landing page for a fictional luxury hair salon in Hamburg. The project focuses on elegance, trust, and conversion-driven design, using HTML, CSS, and JavaScript to create a polished online presence for a local business.

What I built:
- luxury brand-inspired homepage
- service and pricing sections
- gallery with interactive filtering
- client testimonials and social proof
- contact form and CTA sections
- mobile-friendly layout and smooth user experience
- SEO-friendly structure and metadata

Technologies used:
- HTML5
- CSS3
- JavaScript

This project goes beyond basic front-end coding because it shows real business-oriented web design thinking: structure, visual hierarchy, user experience, brand presentation, and deployment readiness.
