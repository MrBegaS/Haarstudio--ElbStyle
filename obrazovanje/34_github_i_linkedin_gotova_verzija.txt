# Haarstudio ElbStyle

A premium, responsive landing page for a fictional hair salon in Hamburg, Germany.

## Overview
This project is a modern marketing website designed for a luxury salon brand. The goal was to create a polished, conversion-focused online presence that communicates premium service quality, professional care, and a refined customer experience.

## Features
- Premium salon-inspired visual design
- Responsive layout for desktop, tablet, and mobile
- Service and pricing sections
- Gallery with interactive filtering
- Testimonials and social proof
- Contact form and booking CTA
- SEO-friendly structure and metadata
- Clean, semantic HTML and lightweight JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript
