CSS – KAKO SE PRAVI PREMIUM LOOK

CSS je ono što daje sajtu izgled. HTML pravi strukturu, CSS pravi stil.

------------------------------
1. CSS je "design sistem"
------------------------------
Na početku se definišu boje, dimenzije, fontovi, razmaci. To se radi u :root sekciji.

Primer:

:root {
  --bg: #f7f2ea;
  --text: #1b1b1a;
  --gold: #c2a276;
  --muted: #554b40;
}

Ovo je jako važno jer:
- postojeće boje su u jednom mestu,
- lakše menjaš sve boje,
- dizajn je konzistentan,
- kod je održiv.

------------------------------
2. ZAŠTO KORISTIMO VARIJABLE?
------------------------------
Varijable u CSS-u su kao "naziv boja".
Umesto da pamtite hex kodove u svakom delu, pišeš:

color: var(--gold);

To znači:
- manje grešaka,
- lakše održavanje,
- lakše promene dizajna,
- profesionalniji workflow.

------------------------------
3. OSDOBINE KAO KAKO SE POSTIŽE PREMIUM FEEL
------------------------------
U našem projektu dizajn nije bio "previše dobar" ni "previše obojen". Bio je minimalistički i premium.

Koristi se:
- krem pozadina,
- tamna tipografija,
- zlatni akcenti,
- mnogo belog prostora,
- elegantni fontovi,
- jednostavni, čisti buttoni,
- razrešeni elementi sa malo radius-a.

Ovo je tipično za premium brand web dizajn.

------------------------------
4. STRANI FONTOVI I TIPOGRAFIJA
------------------------------
U HTML-u smo dodali Google Fonts:
- Cormorant Garamond za naslove,
- Inter za telo teksta.

To je važno zato što font daje karakter:
- naslovi su elegantni,
- tekst je čitljiv,
- celokupni look je više "luxury" nego "običan".

Bez dobrog fonta, čak i dobra struktura izgleda obično.

------------------------------
5. CSS GRID I FLEXBOX
------------------------------
U fazi dizajna koristio sam dva glavna sistema za raspored:
- Flexbox za header, navigaciju, dugmad, footer sekcije,
- Grid za galerije, usluge, layout sekcija.

Flexbox koristimo kada element treba da se rasporedi u red ili kolonu.
Grid koristimo kada imamo više kolona i želimo precizno raspoređivanje.

Primer:

.service-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1.4rem;
}

Ovo znači:
- 3 kolone na većim ekranima,
- 2 ili 1 kolona na manjim ekranima.

------------------------------
6. RESPONSIVNOST
------------------------------
CSS treba da radi i na telefonu i na desktopu. Zato su tu media queries.

Primer:

@media (max-width: 760px) {
  .intro-grid,
  .about-grid,
  .contact-grid {
    grid-template-columns: 1fr;
  }
}

Ovo znači:
- na velikim ekranima sekcije imaju 2 kolone,
- na manjim ekranima prelaze u 1 kolonu.

To je ključno za kvalitetan web dizajn.

------------------------------
6.1. KONKRETAN PRIMER IZ PROJEKTA
------------------------------
U ovom projektu su primenjene konkretne media queries za tablet i telefon:

@media (max-width: 960px) {
  .service-grid,
  .benefits-grid,
  .gallery-grid {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

@media (max-width: 760px) {
  .intro-grid,
  .about-grid,
  .contact-grid,
  .service-grid,
  .benefits-grid,
  .gallery-grid,
  .footer-grid {
    grid-template-columns: 1fr;
  }
}

Ovo znači da:
- tablet verzija zadržava 2 kolone,
- mobilna verzija prelazi na 1 kolonu,
- navigacija se pretvara u hamburger meni,
- sadržaj ostaje pregledan i lak za korišćenje.

------------------------------
7. VISUAL HIERARCHY
------------------------------
Vizuelna hijerarhija znači da se najvažniji sadržaji ističu.

U projektu to je uradjeno sa:
- velikim naslovima,
- ujednačenim razmacima,
- bold tekstovima,
- gold eyebrow labelima,
- jasno definisanim CTA dugmadima.

Na taj način korisnik odmah zna šta je važno.

------------------------------
8. KARTICE (CARDS)
------------------------------
Kartice su u projektu korišćene za usluge i benefit sekcije.
CSS definiše:
- border,
- radius,
- box-shadow,
- padding,
- hover efekat.

Na taj način sadržaj izgleda kao da je "uređen" i profesionalan.

------------------------------
9. BUTTONS
------------------------------
Button design je važan u sajtovima za biznis.
Treba da budu:
- vidljivi,
- mobilni,
- kontrastni,
- lako klikljivi.

U projektu su korišćeni okrugli buttons sa tamnom i prozirnom varijantom.

------------------------------
10. ŠTA JE KLJUČNO U CSS-u?
------------------------------
Najvažniji deo je razumevanje da CSS ne radi "samo boje".
CSS određuje:
- raspored,
- tipografiju,
- razmak,
- međusobni raspored elemenata,
- ponašanje na mobilnim uređajima,
- premium kvalitet dizajna.

To je ono što pravi razliku između obične i profesionalne stranice.

------------------------------
11. ZAKLJUČAK
------------------------------
CSS je proces oblikovanja, ne samo "boje i fontovi".
On pravi celokupnu estetiku, usklađuje sadržaj i omogućava da se stranica malo po malo pretvori u dobar, realan brand.

Ako naučiš CSS dobro, već znaš da praviš profesionalne stranice.
