# Haarstudio ElbStyle

A modern, premium landing page for a fictional hair salon in Hamburg, Germany.

## Overview
This project is a responsive static website created for a luxury salon brand. The goal was to design a polished online presence that reflects professionalism, premium service quality, and a strong local market appeal.

## Design Focus
- luxury visual style
- elegant typography and spacing
- premium color palette
- strong conversion-oriented call-to-action sections
- mobile-first, responsive layout
- clear structure for services, gallery, reviews, and contact

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive homepage layout
- Service overview section
- Visual gallery with interactive filtering
- Customer testimonials
- Contact section with inquiry form
- SEO-friendly structure
- Modern UX patterns for local business presentation

## Files Included
- `index.html` – main page content and structure
- `styles.css` – design, layout, responsive styling
- `script.js` – interactive effects and form behavior
- `robots.txt` – crawler instructions
- `sitemap.xml` – sitemap file for search engines
